# Installing Prismalama

![Prismalama Logo](logo.jpg)

This file lists **supported install paths**. Defaults baked into the **Arch package** are documented in **[README-PKGBUILD.md](README-PKGBUILD.md)** and generated by the root **[PKGBUILD](PKGBUILD)** into **`/etc/default/ollama`**.

## Arch Linux (recommended)

1. Build or install **`prismalama-ollama`** from this repository — see **[README-PKGBUILD.md](README-PKGBUILD.md)**.
2. Typical commands from the directory that contains **`PKGBUILD`**:

```bash
makepkg -sfi
sudo systemctl enable --now ollama
```

3. Edit **`/etc/default/ollama`** for persistent tuning (models dir, GPU, streaming). Prefer a **systemd drop-in** for overrides if you want them to survive package upgrades (examples in README-PKGBUILD).

## From source (developers)

See **[docs/DEVELOPER.md](docs/DEVELOPER.md)**. Running **`go run . serve`** or a locally built **`ollama`** binary uses **Go `envconfig` defaults**, which **differ** from the Arch **`/etc/default/ollama`** file — for example **`OLLAMA_LAYER_STREAMING`** is **off when unset** in code (integration tests assert this), while the package ships **`OLLAMA_LAYER_STREAMING=1`**.
